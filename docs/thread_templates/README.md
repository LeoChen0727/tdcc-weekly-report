# Codex Thread Templates

Use these templates to start a new Codex thread without carrying a long
conversation forward.

- `daily_production.md`: Daily Taiwan stock recommendation and daily PDF source workflow.
- `research_backtest.md`: Backtest, model research, parameter evidence, and historical performance workflow.
- `tdcc_weekly.md`: TDCC weekly large-holder flow and weekly PDF workflow.
- `ci_release.md`: Branch, PR, Actions, Pages/raw alignment, automation, and docs handoff workflow.

Each template intentionally starts with the repo rule gate. Paste only the
template that matches the current task, then add the concrete objective and
completion condition.
